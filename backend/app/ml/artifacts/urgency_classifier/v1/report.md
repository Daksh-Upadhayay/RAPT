# Urgency classifier v1

Weak supervision: keyword/heuristic rules (`app/ml/weak_labels.py`) label the training
data, then TF-IDF word 1-2-grams + tone features (VADER sentiment, caps ratio, `!`/`?`
counts, length) → XGBoost learns from those labels. Class-balanced sample weights.
Generated by `scripts/train_urgency_model.py`; numbers are in `metrics.json`.

Weak label distribution (train, 3773 rows):
low 2133 (57%), medium 1247 (33%), high 393 (10%).

## Summary

| model | val (weak) macro-F1 / acc | test (weak) macro-F1 / acc | handwritten (human) macro-F1 / acc |
|---|---|---|---|
| XGBoost | 0.90 / 0.91 | 0.88 / 0.88 | 0.52 / 0.54 |
| LogReg baseline | 0.89 / 0.90 | 0.85 / 0.84 | 0.58 / 0.60 |

**Rules alone on the hand-written set:** macro-F1 0.68 / accuracy 0.67.

- **val / test (weak)**: agreement with the rules' labels on held-out data — measures how
  well the model *learned the rules*, not how well it predicts real urgency.
- **handwritten (human)**: agreement with urgency labels a person assigned. **This is the
  headline number.** Compare it with "rules alone": the model earns its place only if it
  does at least as well as the rules it was trained on.

## Labeling functions

together with a MEDIUM rule; MEDIUM if one weak HIGH or any MEDIUM rule fires; otherwise LOW.
